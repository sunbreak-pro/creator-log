# creator-log

会社員 1 年目。Unity のターン制カードゲームと異世界の小説を個人で作り、作る途中を X に出しています。

## この場所は何か

X に出す投稿文を、先にここへ書いて残す場所です。X はその写しです。週に 1 回、反応の数字を `metrics.csv` に手で記録します。

## 発信の軸(2026-11-03 決定)

- 最初の 12 週(2026-11-03〜2027-02-01)は、ゲーム original-card-battle の開発記録を週 3 本、小説を週 1 本、X に出します。
- 目標にするのは投稿数(12 週で 48 本)だけです。フォロワー数は記録するだけです。
- 収益化の機能は、会社の許可が出るまで使いません。

## 構成

- `posts/YYYY/MM/DD-slug.md` は投稿文です。先頭に date・platform・url・type・work を書きます。ひな形は `posts/_template.md` です。
- `weekly/YYYY-Www.md` は週の振り返りです。ひな形は `weekly/_template.md` です。
- `metrics.csv` は週 1 行の数字です(週・フォロワー・インプレッション・投稿数)。
- `decisions.md` は軸・頻度・線引きの決定と日付です。

## 投稿の型

1. 画面の before / after
2. 数字(テスト件数、作った枚数)
3. 失敗と学び
4. 決めたことと理由
5. 小説の掌編か設定の一片

- 4 週目(2026-12-07)までは道具を作りません。習慣が先です。
- 投稿は手で貼ります。Claude Code に任せるのは下書きと週次の振り返りだけで、5 週目(2026-12-08)からです。
